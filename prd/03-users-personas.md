# 3. Target Users & Personas

## User Groups
- **Loksewa Aspirants (Primary):** all levels — Kharidar, Nayab Subba, Officer, etc.
- **Teachers/Content Contributors (Secondary):** contribute notes/questions, moderate discussions (via Admin Panel).
- **Admins:** manage content, users, notices, and app config via separate web Admin Panel (see 46-admin-panel.md).

## Personas

### Serious Aspirant
Full-time or alongside a job; studies daily; needs structured content + mock tests; tracks progress vs others (Leaderboard). Values reliability — app must not crash during a timed test.

### Casual Daily Checker
Opens briefly multiple times a day for Current Affairs + Question of the Day. Values speed, minimal friction, useful push notifications.

### Community Learner
Heavy Discussion module user; asks/answers questions, builds reputation. Values clean, fast, fair moderation.
