# 2. Goals & Success Metrics

## 2.1 Business Goals
- Establish Loksewa Solution as a top-ranked education app in its category.
- Build a large, engaged, daily-active user base.
- Create a scalable content and monetization foundation (ads now, premium later).
- Build a re-skinnable architecture for other exam categories/clients (see 05-app-config.md).

## 2.2 User Goals
- Structured subject/chapter wise study material.
- MCQ + subjective practice similar to real exam patterns.
- Timed mock tests simulating the real exam.
- Daily current affairs and Gorkhapatra summaries.
- Personal progress tracking and weak-area discovery.
- Discussion with other aspirants.
- Easy bookmarking/revisit.

## 2.3 Success Metrics
- DAU / MAU
- Avg session duration & sessions per day per user
- Mock test completion rate
- Retention: Day 1 / Day 7 / Day 30
- Discussion engagement (posts, comments per active user)
- Crash-free sessions: **99.5%+**
- App store rating: **4.5+**
